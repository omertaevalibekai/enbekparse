# enbek.kz Recruiter

Агент для **холодного поиска кандидатов** на государственной бирже труда Казахстана [enbek.kz](https://www.enbek.kz) (185 000+ публичных резюме).

По заданной вакансии (должность + город + опыт) собирает резюме соискателей и сохраняет их в локальную базу: позиция, город, стаж, история работы по местам, зарплатные ожидания, образование, навыки, языки.

## Возможности

- Поиск резюме по должности, городу и требуемому опыту
- Извлечение данных кандидата без авторизации:
  - желаемая должность
  - город / район проживания
  - общий стаж («3 года»)
  - история работы — компании, должности, периоды
  - зарплатные ожидания, образование, навыки, языки, пол/возраст
- **Опционально с авторизацией** (email + пароль) — раскрытие имени и телефона кандидата
- Локальная база SQLite с дедупликацией по ID резюме
- Сессия логина кэшируется (`session.json`) — повторно вводить пароль не нужно

## Установка

```bash
cd enbek-recruiter
python -m venv venv
venv\Scripts\activate          # Windows
pip install -r requirements.txt
playwright install chromium
```

## Использование

### Поиск кандидатов

```bash
python main.py --keyword "водитель" --location Астана --exp 3-6 --pages 5
```

### Просмотр собранной базы

```bash
python main.py --show
```

### Очистка базы

```bash
python main.py --clear
```

### С авторизацией (раскрывает имя и телефон)

```bash
python main.py --keyword "менеджер" --location Алматы --pages 3 \
  --email you@mail.kz --password ВашПароль
```

## Параметры командной строки

| Параметр | Описание |
|---|---|
| `--keyword` | Должность / ключевое слово (напр. «разработчик») |
| `--location` | Город: Алматы, Астана, Шымкент, Актобе, Атырау и др. |
| `--exp` | Опыт: `no` (без опыта), `1-3`, `3-6`, `6+` |
| `--pages` | Сколько страниц обработать (~10 резюме на страницу) |
| `--email` | Логин enbek.kz (email или телефон) — для контактов |
| `--password` | Пароль enbek.kz |
| `--show` | Показать все резюме из базы |
| `--clear` | Очистить базу |
| `--visible` | Показать окно браузера (отладка) |

## Структура проекта

```
enbek-recruiter/
├── main.py          — точка входа, разбор CLI-аргументов
├── agent.py         — оркестрация через LangGraph (сбор → извлечение)
├── browser.py       — Playwright: логин, навигация, парсинг резюме
├── models.py        — Pydantic-модели (SearchQuery, Candidate)
├── storage.py       — SQLite: сохранение, дедупликация, миграции схемы
├── requirements.txt — зависимости
├── candidates.db    — база собранных резюме (создаётся автоматически)
└── session.json     — кэш cookies после входа (создаётся при --email/--password)
```

## Как это работает

Агент построен на **LangGraph** — граф из двух узлов:

```
collect_links ──(есть ещё страницы?)──> collect_links
      │
      └──(страницы кончились)──> extract_and_save ──> END
```

1. **collect_links** — открывает страницу поиска
   `https://www.enbek.kz/ru/search/resume?prof=...&region=...&experience=...&page=N`
   и собирает ссылки на резюме.
2. **extract_and_save** — заходит в каждое резюме, парсит текст страницы
   через регулярные выражения по меткам («Опыт работы», «Город/Район»,
   «Трудовая деятельность» и т.д.) и сохраняет в базу.

Если переданы `--email` и `--password`, перед сбором агент авторизуется
через `passport.enbek.kz` и для каждого резюме дополнительно кликает
«Показать контактные данные», извлекая телефон и имя.

## Технологии

- **Playwright** — headless-браузер (Chromium)
- **LangGraph** — оркестрация шагов
- **Pydantic v2** — модели данных
- **SQLite** — локальное хранилище

## Ограничения

- Фильтры enbek.kz по опыту и региону **нестрогие**: портал трактует
  `experience` как «желаемый опыт под вакансию», а не фактический стаж
  кандидата, а фильтр региона подмешивает соседние области. При
  необходимости жёсткой выборки добавьте пост-фильтрацию по полям
  `city` и `experience` после сбора.
- Имя и телефон доступны только при авторизации (зарегистрированный
  аккаунт enbek.kz).
- Парсинг построен на текстовых метках страницы — при редизайне
  enbek.kz регулярные выражения в `browser.py` потребуют обновления.

## Назначение

Инструмент для рекрутеров: формирование лонг-листа кандидатов под
конкретную вакансию. Дальнейшая связь с кандидатами — через платформу
enbek.kz.
